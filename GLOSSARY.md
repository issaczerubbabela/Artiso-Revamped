# Artiso

A reference-preparation companion an artist keeps open beside their physical
paper while drawing by hand, using a measured grid to transfer proportions.

## Viewing the reference

**View Rotation**:
The angle, free and continuous, at which the artist is looking at the reference;
the image, crop and grid turn together, like turning a sheet of paper on a desk.
It changes how the reference is seen, never the reference itself.
_Avoid_: Canvas rotation, rotate (unqualified)

**Rotate (edit)**:
A quarter-turn (90°, 180°, 270°) recorded in the reference's edits, changing
which way up the reference is prepared and exported.
_Avoid_: Straighten, view rotation

**Touch Lock**:
A state in which the canvas ignores all touch input while keeping the current
view exactly as it is; distinct from Presentation mode.
_Avoid_: Freeze, presentation lock

## Transferring to paper

**Cell Focus**:
Picking out one grid cell to copy, with the rest of the reference dimmed but
still visible, and stepping from cell to cell in reading order.
_Avoid_: Spotlight, highlight, isolate

**Done Cell**:
A cell the artist has marked as already transferred to paper.
_Avoid_: Completed square, checked cell

**Drawing Check**:
Comparing a Check Photo against the reference to find proportion errors.
_Avoid_: Onion skin, overlay compare

**Check Photo**:
The latest photo of the artist's own drawing, aligned to the paper by its four
corners and kept with the reference; never part of the reference itself.
_Avoid_: Progress photo, drawing overlay

**Measurement**:
A temporary distance drawn across the reference and read in paper units and
in cells; never saved.
_Avoid_: Ruler line, annotation

## Input

**Pencil-only Drawing**:
The mode in which only a stylus marks the canvas while fingers pan, zoom and
rotate; it switches on the first time a stylus is detected.
_Avoid_: Palm rejection (that is a consequence, not the mode)
